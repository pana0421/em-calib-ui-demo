# 电磁场校准系统
基于 PySide6 开发的电磁场校准Qt界面原型，为科创课题前期演示原型。

## ✨ 功能介绍
一共包含4套独立校准页面：
1. TEM室校准（10kHz–300MHz）
2. GTEM室校准
3. 暗室射频校准
4. 工频磁场校准

通用功能：
- 设备状态在线显示（离线/就绪）
- 参数设置：设定值、步长、频率等
- 实时绘图：绘制设定值与实测值曲线
- OCR模拟识别面板（模拟仪器读数识别）
- 数据表格记录测量点
- 支持数据导出为CSV文件
